Task Manager is a web application designed to help users organize and manage their daily tasks easily and efficiently. The website allows users to create an account, log in securely, and manage their personal tasks through a simple and user-friendly interface.

The system supports full CRUD operations, allowing users to:

* Add new tasks
* View existing tasks
* Edit task information
* Delete tasks

Each task includes a title, date, and status. The website also includes form validation using JavaScript and PHP to ensure correct user input and improve security.

The project was developed using:

* HTML
* CSS
* Bootstrap
* JavaScript
* PHP
* MySQL

The design focuses on simplicity, soft colors, and an organized layout to provide a comfortable user experience.
